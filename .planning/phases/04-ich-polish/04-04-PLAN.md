## Empfehlung für die Startup-Phase

### Kurzfristig (Pre-Seed / Jetzt): Freelancer-Hybrid

**Empfohlenes Vorgehen:**

1. **Web-App zuerst** — Der aktuelle Prototyp (Next.js + localStorage) validiert das Konzept. Vor nativen Apps: echte Nutzer gewinnen.
2. **Backend-First-Ergänzung** — Supabase als Backend (Auth, DB, Storage) ist für Startups ideal: Free Tier ausreichend für erste 1.000 Nutzer, skalierbar, keine Lock-In-Risiken.
3. **Einen Senior Full-Stack Freelancer** für 2–3 Monate engagieren: Web-App production-ready machen, Backend anbinden, Stripe integrieren.
4. **iOS via React Native / Expo** — Teilt 80% des Next.js-nahen Code. Kein separater iOS-Entwickler nötig.
5. **Android automatisch** via Expo EAS Build.

**Geschätzte Gesamtkosten (Empfehlung):**
- Entwicklung: 40.000–70.000 €
- Laufend: 80–200 €/Monat
- Zeitplan: 4–5 Monate bis Launch

### Mittelfristig (Seed-Phase / nach erstem Umsatz):
- In-house Full-Stack Entwickler einstellen (60.000–80.000 €/Jahr)
- UX Designer (Teilzeit oder Freelance, 1.500–3.000 €/Monat)
- Agentur nur für spezifische Sprints (z.B. App Store Optimierung, Marketing-Materialien)

### Premium-Umsatz-Kalkulation (Break-Even):

Bei €2,99/Monat bzw. €19,99/Jahr:
- Break-Even auf Freelancer-Entwicklung (60.000 €): ~1.680 Jahres-Abos oder ~1.670 Monats-Abos
- Bei 2% Conversion von 10.000 MAU: 200 zahlende Nutzer → ~4.000 €/Monat → positiver Cashflow nach ~15 Monaten
- **Ziel für Seed-Pitch:** 1.000 aktive Nutzer, 50 zahlende Nutzer als Proof-of-Concept

### Provisions-Modell (Verträge):
- Strom: ~30–50 € Provision pro Abschluss
- Internet: ~30–60 € Provision pro Abschluss  
- Versicherungen: ~20–80 € Provision pro Abschluss
- Bei 100 Abschlüssen/Monat: 3.000–10.000 € zusätzlicher Umsatz
- Dieses Modell skaliert mit Nutzerzahl — wichtiger Hebel für profitables Wachstum
