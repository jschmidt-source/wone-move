## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, chat bubble tail |
| sm | 8px | Compact element spacing, between-pill gap |
| md | 16px | Default section padding, card inner padding |
| lg | 24px | Section vertical gap, profil-screen section spacing |
| xl | 32px | Layout top/bottom padding, paywall section gap |
| 2xl | 48px | Major section breaks (paywall feature table) |
| 3xl | 64px | Page-level top spacing (empty state illustration) |

Exceptions:
- Touch targets on disabled buttons (Account löschen, Logout): minimum 44px height per mobile accessibility standard
- Bottom sheet drag handle area: 20px height (visually 4px pill, 20px tappable)
- BottomNav items: 56px height (established in Phase 1, unchanged)
- Werbebanner: 48px height fixed

**Accent (#646efb) reserved for:**
1. Avatar circle background (Profil-Screen initials container)
2. Primary CTA buttons: "Jetzt upgraden" (Paywall), "Weiter" (Onboarding carry-over)
3. Progress bar fill (Profil-Screen: "18 von 32 Aufgaben")
4. User chat bubbles (Chatbot screen)
5. Upgrade-Button in inline Paywall-Banner inside chat feed
6. BottomNav active indicator (established Phase 1)
7. Ring focus state on inputs

Accent is NOT used for: disabled states, destructive actions, ad banner, AI chat bubbles, settings rows.

## Component Patterns

### Avatar (Profil-Screen)

- Large circle: 80px diameter, background `#646efb`, white initials text 28px weight 700
- Text content: first letter of Vorname + first letter of Nachname (e.g. "LM" for "Lea Müller")
- No image upload in Phase 4 (prototype)

### Chat Bubbles (Chatbot)

- User bubble: background `#646efb`, text white 14px/400, border-radius 16px (rounded-2xl), aligned right, max-width 80% viewport
- AI bubble: background `#ffffff` (card), text `#1c2642` 14px/400, border-radius 16px (rounded-2xl), aligned left, max-width 80% viewport
- Timestamp/sender label: 12px/400 `#5b6377`, above each bubble group

### Inline Paywall Banner (Chatbot)

- Full-width card inside chat feed (not overlay)
- Background: `#d2d5fc` (accent light), border `#646efb` 1px
- Schloss icon (lucide `Lock`) + message text + "Jetzt upgraden →" button (primary, `#646efb`)
- Appears as the 4th message in the feed after user submits their first message

### Premium Lock Card (Dokumentenspeicher)

- Renders as 3rd card slot in doc list
- Background: `#ffffff`, border: `#d2d5fc` dashed 2px
- Content: lucide `Lock` icon (20px, `#646efb`) + "Unlimitiert mit Premium speichern" (14px/600) + "Upgrade →" link text (`#646efb`)
- No modal on tap — navigates directly to `/ich/premium`

### Werbebanner (Aufgaben)

- Fixed position at top of content area, above first checklist category
- Height: 48px, background: `#f6f7f7`, border-bottom: 1px `#d2d5fc`
- Text: "Anzeige: Jetzt Strom vergleichen →" (14px/400, `#5b6377`)
- Right side: X icon (lucide `X`, 16px, `#5b6377`) — tap triggers toast (not dismiss)
- Arrow "→" is decorative text, not a functional link in prototype

### Push Toggle Bottom Sheet

- Follows Phase 3 `AbschlussSheet` pattern (Bottom Sheet via Radix/Base UI)
- Content: iOS-style notification preview mock (rounded card, app icon, title, body), toggle list (Aufgaben-Erinnerungen, Fristen-Benachrichtigungen), "Aktivieren" primary button
- Not a sub-screen — renders as sheet over `/ich/einstellungen`

### Paywall Comparison Table

- Two-column table: Free | Premium
- 8 feature rows (from ROADMAP.md): Checkliste, Anleitungen, Zeitplan, KI Chatbot (3 Chats), KI Chatbot (Unlimited), Dokumentenspeicher (2), Dokumentenspeicher (Unlimited), PDF-Export
- Check marks: lucide `Check` (`#646efb`) for included, lucide `X` (`#ef4444`) for excluded
- Pricing: €2,99/Monat · €19,99/Jahr (24px/700 `#646efb`)

### Disabled Settings Rows

- "Account löschen": 14px/400, color `#ef4444` at 50% opacity, no chevron, tap shows toast
- "Logout": 14px/400, color `#5b6377`, no chevron, tap shows toast
- Both rows have `pointer-events: auto` (tappable for toast), but visually non-actionable

## Interaction Contracts

| Interaction | Trigger | Response |
|-------------|---------|----------|
| Profil header icon 💬 | Tap | `router.push('/ich/chatbot')` |
| Profil header icon ⚙️ | Tap | `router.push('/ich/einstellungen')` |
| Profil Dokumentenspeicher card | Tap | `router.push('/ich/dokumente')` |
| Chatbot input submit (1st–3rd) | Send | Appends user bubble + AI response bubble, increments `chatCount` in `chatbotStore` |
| Chatbot input submit (4th) | Send | Appends user bubble, then renders inline paywall banner (no AI response) |
| Chatbot inline upgrade button | Tap | `router.push('/ich/premium')` |
| Dok Premium-Lock-Card | Tap | `router.push('/ich/premium')` |
| Übergabeprotokoll export button | Tap | `router.push('/ich/premium')` |
| Paywall "Jetzt upgraden" | Tap | Toast "Danke! Premium-Funktion folgt in der Vollversion." + `router.back()` |
| Paywall "Kostenlos weitermachen" | Tap | `router.back()` |
| Ad banner X button | Tap | Toast "Werbung kann nicht ausgeblendet werden. Upgrade auf Premium." |
| Push toggle (Einstellungen) | Toggle on | Opens Bottom Sheet (does not navigate) |
| Account löschen / Logout | Tap | Toast "Nur in der Vollversion verfügbar." (no navigation, no state change) |
| Datenschutz / Impressum row | Tap | `router.push('/ich/datenschutz')` / `router.push('/ich/impressum')` |
| All back navigation | Back button / header chevron | `router.back()` |
| Empty state (100% Aufgaben) | Auto-trigger on last check | Konfetti animation plays, screen replaces checklist content |
