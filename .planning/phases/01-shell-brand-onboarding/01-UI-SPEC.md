## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding, step-indicator dot spacing |
| sm | 8px | Button icon-to-label gap, input helper text margin, tag internal padding |
| md | 16px | Default horizontal screen padding, card inner padding, form field vertical gap |
| lg | 24px | Section vertical gap, onboarding step content top margin |
| xl | 32px | Welcome screen headline-to-subline block gap |
| 2xl | 48px | Splash logo vertical centering offset |
| 3xl | 64px | Bottom navigation safe-area bottom padding (total nav height target) |

Exceptions:
- Touch targets: minimum 44px height for all interactive tiles (Kachel-Auswahl), toggle rows, and navigation tabs — per mobile accessibility guidelines.
- Bottom navigation tab hit area: 56px height (nav bar visual) + system safe-area inset below.
- Step indicator dots: 8px diameter, 4px gap between dots.

**Source:** 8-point grid default; touch target exceptions from ROADMAP.md screen specs for Kachel-Auswahl and bottom nav.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (Regular) | 1.5 | Default text, onboarding hint copy, toggle labels |
| Label | 14px | 700 (Bold) | 1.4 | Step indicator text, input labels, badge text, bottom navigation tab labels |
| Heading | 20px | 700 (Bold) | 1.3 | Onboarding step titles ("Wann ziehst du um?"), welcome subline |
| Display | 28px | 700 (Bold) | 1.2 | Welcome screen headline, celebration screen headline |

Font family: `'Plus Jakarta Sans', sans-serif` — apply as `fontFamily.sans` in `tailwind.config.ts`.

Weight system: two weights only — 400 (Regular) for body copy and 700 (Bold) for all labels, headings, display text, and interactive elements. No intermediate weights.

**Source:** ROADMAP.md success criterion 1 (Plus Jakarta Sans); sizes derived from screen hierarchy in ROADMAP.md Phase 1 screen specs. Four sizes: 16/14/20/28px. Nav tab labels use Label (14px) — the 2px difference from the original 10px spec is imperceptible at mobile density. Semibold (600) removed; all label/interactive weights unified to Bold (700).

## Color

| Role | Hex | Tailwind Token | Usage |
|------|-----|----------------|-------|
| Dominant (60%) | `#f6f7f7` | `background` | Page background, screen surfaces |
| Secondary (30%) | `#1c2642` | `foreground` / `card-foreground` | Body text, nav active icon, card text on light bg |
| Accent (10%) | `#646efb` | `primary` | Reserved elements listed below |
| Accent light | `#d2d5fc` | `primary-foreground` / `muted` | Tile selected background, step indicator active fill (light variant) |
| Muted text | `#5b6377` | `muted-foreground` | Placeholder text, secondary body copy, nav inactive labels |
| Destructive | `#ef4444` (Tailwind red-500) | `destructive` | No destructive actions in Phase 1 — defined for completeness |

**Accent (`#646efb`) is reserved for:**
1. Splash screen background (full-bleed)
2. "Jetzt starten" primary button (Welcome screen)
3. "Weiter" button on each onboarding step
4. "Los geht's →" CTA on Celebration screen
5. Step indicator active dot / filled segment
6. Selected state border on Kachel-Auswahl tiles (Schritt 3 + 4)
7. Active toggle fill in Schritt 5 toggle list

**Accent is NOT used for:** body text, backgrounds (except splash), secondary elements, nav inactive states, card surfaces, or input borders at rest.

**60/30/10 split:**
- 60% `#f6f7f7` — screen backgrounds, card fills, form field backgrounds
- 30% `#1c2642` — all body text, nav bar background, step indicator inactive dots
- 10% `#646efb` — CTAs, active states, accents listed above

**Source:** CLAUDE.md Brand table (all five tokens locked). Split allocation derived from screen inventory.

## Screen Inventory & Interaction Contracts

### 1. Splash Screen

- Full-bleed background: `#646efb`
- Logo: centered vertically and horizontally, white wordmark + icon
- Loading animation: pulsing opacity or spinning ring in white, 1.5s duration, auto-advance to Welcome screen
- No user interaction required — auto-navigate after animation completes
- Duration: 1500ms then `router.push('/welcome')`

### 2. Welcome Screen

- Background: `#f6f7f7`
- Display headline: "Dein erster Auszug. Wir begleiten dich." — 28px, weight 700, color `#1c2642`
- Subheading: "Dein persönlicher Umzugsplan in 2 Minuten." — 20px, weight 700, color `#5b6377`
- Vertical spacing between headline block and CTA: 32px
- Primary CTA button "Jetzt starten": full-width, height 52px, background `#646efb`, text white 16px weight 700, border-radius 12px
- Button positioned in lower third of screen with 16px horizontal margin
- No secondary CTA on this screen

### 3. Onboarding Step Indicator (global, Schritte 1–5)

- Rendered at top of each onboarding screen below the status bar
- 5 dots, 8px diameter each, 4px gap
- Active dot: `#646efb` filled, 12px diameter (slightly larger, aligned to 4-point grid)
- Completed dot: `#646efb` filled, 8px
- Inactive dot: `#d2d5fc` filled, 8px
- Step counter text: "Schritt X von 5" — 14px, weight 700, color `#5b6377`, centered below dots
- Top padding from screen edge: 16px

### 4. Onboarding Schritt 1 — Umzugsdatum

- Screen title: "Wann ziehst du um?" — 20px, weight 700, `#1c2642`
- Date picker: mock implementation — display a native `<input type="date">` styled with Tailwind to match brand, or a shadcn Popover + Calendar component
- Selected date displayed in a pill badge below the picker: 14px, weight 700, `#646efb` background `#d2d5fc`
- "Weiter" button: full-width, 52px height, `#646efb`, white text, 16px weight 700, border-radius 12px, 16px horizontal margin, pinned 16px above bottom safe area

### 5. Onboarding Schritt 2 — Wohin?

- Screen title: "Wohin ziehst du?" — 20px, weight 700, `#1c2642`
- Two inputs stacked with 16px gap:
  - Label: "PLZ der neuen Wohnung" — 14px weight 700 `#1c2642`
  - Input field: height 52px, border 1.5px `#d2d5fc` at rest, `#646efb` on focus, border-radius 10px, 16px padding, 16px font size weight 400 `#1c2642`
  - Placeholder text: "z.B. 80331" / "z.B. Hamburg" — `#5b6377`
  - Label: "Von welcher Stadt?" — same treatment
- Keyboard type: `inputmode="numeric"` for PLZ field, `inputmode="text"` for city field
- "Weiter" button: same spec as Schritt 1

### 6. Onboarding Schritt 3 — Umzugsorganisation

- Screen title: "Wie organisierst du deinen Umzug?" — 20px, weight 700, `#1c2642`
- 4-tile grid (2×2): tiles are tappable selection cards
- Tile spec:
  - Size: full width split into 2 columns with 12px gap, each tile height 88px
  - Border-radius: 14px
  - Default state: background white, border 1.5px `#d2d5fc`
  - Selected state: background `#d2d5fc`, border 2px `#646efb`
  - Icon: 24px emoji centered above label
  - Label: 14px weight 700 `#1c2642`, centered
- Tiles: "Ich alleine", "Mit Freunden", "Umzugsfirma", "Gemischt"
- Selection: single-select (only one tile active at a time)
- "Weiter" button: same spec — disabled until a tile is selected (opacity 0.4, not tappable)

### 7. Onboarding Schritt 4 — Priorität

- Screen title: "Was ist dir am wichtigsten?" — 20px, weight 700, `#1c2642`
- 4-tile grid (2×2): same tile spec as Schritt 3
- Tiles: "💰 Günstig", "⚡ Schnell", "😌 Stressfrei", "🌱 Nachhaltig"
- Selection: single-select
- Tile height: 88px (same as Schritt 3)
- "Weiter" button: same spec — disabled until selection made

### 8. Onboarding Schritt 5 — Hast du bereits?

- Screen title: "Was hast du schon erledigt?" — 20px, weight 700, `#1c2642`
- Hint text: "Keine Sorge — du kannst alles jederzeit ändern." — 14px weight 400, `#5b6377`, below title, 8px gap
- 4 toggle rows stacked with 8px gap:
  - Row height: 56px (touch target met)
  - Layout: label left, toggle right
  - Label: 16px weight 400 `#1c2642`
  - Toggle: shadcn Switch component — active color `#646efb`, inactive `#d2d5fc`
  - Background: white card, border-radius 10px, 16px horizontal padding
- Items: "Neue Wohnung gefunden", "Transport organisiert", "Strom & Internet geregelt", "Ummeldung vorbereitet"
- All start in OFF state (pre-checked = OFF means user hasn't done it yet; ON = done)
- "Fertig" button: same spec as "Weiter" — always enabled (all toggles optional)

### 9. Celebration Screen

- Background: `#f6f7f7`
- Confetti animation: CSS-based or `canvas-confetti` library — plays automatically on screen mount, duration 3s, colors `#646efb`, `#d2d5fc`, `#1c2642`, white
- Headline: "Dein Umzugsplan ist fertig!" — 28px weight 700, `#1c2642`, centered
- Emoji: 🎉 inline with headline or 48px below headline
- Summary card: white background, border-radius 14px, 16px padding, 24px below headline
  - Content: "Umzugsdatum: [date] · Von: [city] · 23 Aufgaben warten auf dich"
  - Font: 16px weight 400, `#5b6377`
  - Date and city values: weight 700, `#1c2642`
- CTA "Los geht's →": full-width, 52px, `#646efb`, white text, 16px weight 700, border-radius 12px, 16px margin, pinned 16px above bottom safe area
- No back navigation on this screen (onboarding is complete, data already saved)

### 10. Bottom Navigation

- Height: 56px + system safe-area inset (use `padding-bottom: env(safe-area-inset-bottom)`)
- Background: white (`#ffffff`)
- Top border: 1px solid `#d2d5fc`
- 5 tabs: Home | Aufgaben | Verträge | Entdecken | Ich
- Active tab: icon + label color `#646efb`, icon filled variant
- Inactive tab: icon + label color `#5b6377`, icon outlined variant
- Tab label: 14px weight 700 (below icon)
- Icon size: 24px
- Tab hit area: full tab width × 56px (no smaller)
- Active indicator: no underline or pill — color change only
- Phase 1: Home tab active; remaining 4 tabs navigate to placeholder screens

### 11. Placeholder Tab Screens (Aufgaben, Verträge, Entdecken, Ich)

- Background: `#f6f7f7`
- Centered content: icon 40px `#d2d5fc` + label 16px weight 400 `#5b6377`
- Label copy: see Copywriting Contract below
- Bottom nav remains visible on all placeholder screens

## Layout Rules

- **Viewport target:** 375px width primary, 320px minimum, 768px maximum
- **Screen padding:** 16px left and right on all screens (mobile content area = screen width − 32px)
- **Max content width:** 480px — center on screens wider than 480px with auto horizontal margins
- **Bottom navigation:** fixed position, `bottom: 0`, full width, always above content via `z-index: 50`
- **Content scroll area:** `height: 100dvh − 56px − safe-area-inset-bottom` — content scrolls behind fixed nav
- **Onboarding CTAs:** fixed position at bottom of onboarding screens, 16px from bottom nav top edge
- **No horizontal scroll** on any screen in Phase 1
