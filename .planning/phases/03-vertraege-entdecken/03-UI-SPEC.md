## Spacing Scale

Unchanged from Phase 2. Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding, highlight tag spacing, category dot spacing |
| sm | 8px | Card internal vertical rhythm, section header gap, provider card internal element gap |
| md | 16px | Default horizontal screen padding, card inner padding, section header margin, modal padding |
| lg | 24px | Section vertical gap (between Entdecken hub sections), between provider card blocks |
| xl | 32px | Not used in Phase 3 |
| 2xl | 48px | Not used in Phase 3 |
| 3xl | 64px | Bottom navigation safe-area (carried from Phase 1) |

**Phase 3 exceptions (with justifications):**
- Provider card height: auto (content determines height) — provider cards contain variable tag counts; fixed height would clip content on cards with 3 highlight tags
- Bottom sheet handle: 4px × 32px centered at top — matches Phase 2 add-item sheet; consistent handle sizing across all sheets
- Provider card horizontal scroll peek: 12px gap between cards in horizontal scroll strips — matches Phase 2 Wusstest-du-schon pattern (D-06, D-07)
- Preview card width (Entdecken hub strips): 200px — matches Phase 2 horizontal scroll card width exactly; same scroll strip pattern (D-06)
- Horizontal scroll strip first card: 16px left margin (screen edge alignment) — same as Phase 2 scroll strips
- Bottom sheet height (Abschluss-Modal): 60vh minimum, auto-expands to content — allows the multi-step flow to remain in sheet without triggering full-screen route
- Sticky search bar height: 56px — matches BottomNav height for visual rhythm; contains 44px input + 6px vertical padding each side
- FAQ accordion row height: 52px minimum (touch target for accordion trigger)
- Notfallkontakte tap-to-call row height: 56px — same as checklist item rows for touch safety
- Adressänderungen checkbox row height: 56px — same touch target rule as checklist items
- Verträge Hub kachel height: 88px — matches Phase 1 onboarding tile height (same 2×2 grid pattern)
- Filter/sort pill height: 32px — compact affordance, not a primary CTA; 32px is sufficient at 14px label size

**Source:** Phase 2 UI-SPEC.md spacing scale; Phase 3 exceptions derived from ROADMAP.md screen specs and 03-CONTEXT.md decisions.

## Typography

Unchanged from Phase 2. Four sizes, two weights:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (Regular) | 1.5 | Provider card price display (secondary text), FAQ answer body, Spartipps card text, modal intro copy, Adressänderungen party labels |
| Label | 14px | 700 (Bold) | 1.4 | Highlight tags on provider cards, filter/sort options, hub section labels, badge text ("Empfohlen", "Partnerangebot"), FAQ question labels, tab labels (Haftpflicht/Hausrat), Notfallkontakte numbers, step-indicator copy in Abschluss-Modal, rating labels, search autocomplete suggestion text |
| Heading | 20px | 700 (Bold) | 1.3 | Screen headers ("Verträge", "Entdecken", "Stromanbieter vergleichen"), hub section title rows, FAQ screen header, bottom sheet multi-step title |
| Display | 28px | 700 (Bold) | 1.2 | Provider card monthly price "X,XX €/Monat" — hero numeric callout; success screen headline |

**Price display exception:** Provider monthly price uses Display (28px weight 700) for the primary price number only. The unit "€/Monat" is rendered as Body (16px weight 400 `#5b6377`) adjacent to the number. This mirrors the Phase 2 countdown number exception — a single numeric hero value per card, non-content role.

**12px is not used anywhere in Phase 3.** All small-element text (highlight tags, badges, search suggestions, modal field labels, rating text) uses the Label role (14px). Consistent with Phase 1 and Phase 2 decisions.

**Source:** 02-UI-SPEC.md typography table (locked). Price display exception derived from ROADMAP.md Verträge screen spec ("X,XX €/Monat" groß).

### 9. FAQ Screen (`/entdecken/faq`)

**Layout:** Scrollable, 16px horizontal padding.

**Header:**
- Back button: Lucide `ChevronLeft` 24px `#1c2642` left; tap → `router.back()`
- Screen title: "Häufige Fragen" — 20px weight 700 `#1c2642`

**FAQ accordion (shadcn `accordion` or `collapsible` pattern):**
- 10 questions, each as a collapsible row
- Collapsed state: question text (16px weight 700 `#1c2642`) + Lucide `ChevronDown` 20px `#5b6377` right, row height 52px, bottom border 1px `#d2d5fc`

**10 questions and answers:**
1. "Was ist eine Wohnungsgeberbestätigung?" → "Die Wohnungsgeberbestätigung (auch Mieterbescheinigung) ist ein Dokument, das dein Vermieter ausfüllt und das du für die Ummeldung beim Bürgeramt brauchst. Ohne dieses Dokument kannst du dich nicht ummelden."
2. "Wie lange habe ich für die Ummeldung Zeit?" → "Du hast 14 Tage nach dem Einzug Zeit, dich beim Bürgeramt umzumelden. Diese Frist ist gesetzlich vorgeschrieben (§ 17 BMG)."
3. "Was passiert, wenn ich die Ummeldung vergesse?" → "Wenn du die Ummeldung vergisst oder zu spät machst, kannst du ein Bußgeld von bis zu €1.000 erhalten. Melde dich also innerhalb von 14 Tagen um!"
4. "Wie hoch ist die Kaution normalerweise?" → "Die Kaution darf maximal 3 Kaltmieten betragen (§ 551 BGB). Bei einer Kaltmiete von €800 wären das maximal €2.400. Die Kaution muss auf einem separaten Konto angelegt werden."
5. "Brauche ich eine Haftpflichtversicherung?" → "Eine private Haftpflichtversicherung ist zwar keine Pflicht, aber dringend empfohlen. Sie schützt dich vor Schadensersatzansprüchen Dritter — z.B. wenn du versehentlich etwas beschädigst. Kosten: ab ca. €35–50 pro Jahr."
6. "Was ist der Rundfunkbeitrag?" → "Der Rundfunkbeitrag (früher: GEZ) beträgt €18,36 pro Monat und muss pro Haushalt bezahlt werden. Du meldest dich online bei rundfunkbeitrag.de an. Als Erstanmelder in deiner eigenen Wohnung zahlst du den vollen Beitrag."
7. "Wie kündige ich meinen alten Strom-/Internetvertrag?" → "Kündige deinen alten Vertrag schriftlich per Einschreiben oder über die Kunden-App des Anbieters. Beachte die Kündigungsfrist (meist 4 Wochen zum Monatsende oder Vertragsende). Umzug gilt oft als Sonderkündigungsrecht — prüfe deine Vertragsbedingungen."
8. "Kann ich meinen GEZ-Beitrag von der alten Wohnung übernehmen?" → "Ja! Wenn du bereits Rundfunkbeitrag gezahlt hast, kannst du deine Beitragsnummer zur neuen Adresse mitnehmen. Melde einfach deine neue Adresse online bei rundfunkbeitrag.de — du zahlst dann weiterhin nur einen Beitrag."
9. "Wann sollte ich Möbel bestellen?" → "Bestelle Möbel idealerweise 4–6 Wochen vor dem Einzug, da beliebte Möbel oft 2–4 Wochen Lieferzeit haben. Für IKEA-Bestellungen empfiehlt sich eine Bestellung direkt nach der Wohnungsübergabe, sobald du die genauen Maße kennst."
10. "Wie erkenne ich versteckte Schäden bei der Wohnungsübergabe?" → "Achte besonders auf: Wasserflecken an Decken und Wänden (Hinweis auf Feuchtigkeitsschäden), Kratzer und Dellen im Boden, Funktionsfähigkeit aller Fenster, Türen und Schlösser, Zustand der Sanitäranlagen und den Zählerstand von Strom, Gas und Wasser. Dokumentiere alles im Übergabeprotokoll mit Fotos."

## Layout Rules

Carries Phase 1 + Phase 2 rules. Phase 3 additions:

- **Sticky search bar:** `position: sticky; top: 0; z-index: 40; background: #f6f7f7` — always above scrolling Entdecken hub content
- **Search overlay:** positioned `top: 56px` (below sticky search bar), `left: 0; right: 0; bottom: 0`, `z-index: 50` (above sticky bar scrim, below search input itself)
- **Bottom sheet (Abschluss-Modal):** `position: fixed; bottom: 0; left: 0; right: 0; z-index: 60` — above all content including bottom nav scrim; `padding-bottom: env(safe-area-inset-bottom)` for iOS safe area
- **Provider card list:** single-column vertical scroll; no horizontal scroll (cards are full-width within content area)
- **Entdecken horizontal strips:** `overflow-x: scroll; scrollbar-width: none` (hide scrollbar on desktop/Android); `-webkit-overflow-scrolling: touch` for iOS momentum scroll
- **FAQ accordion:** single-column vertical, no horizontal scroll; full width of content area
- **Versicherungen screen:** Haftpflicht/Hausrat tabs sticky below screen header (same sticky pattern as Aufgaben toggle bar: `position: sticky; top: [header height]; z-index: 40`)
- **All sub-screens (FAQ, Spartipps, Notfallkontakte, Adressänderungen):** standard `(main)` layout with bottom nav visible; back button in screen header; content scrolls with header fixed
- **No dead ends:** every sub-screen has `router.back()` via ChevronLeft header button; Abschluss-Modal has X dismiss; search overlay has X dismiss
